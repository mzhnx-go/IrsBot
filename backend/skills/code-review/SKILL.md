# 代码审查技能

## 审查步骤

1. **通读代码**：先理解代码整体结构和意图
2. **检查代码风格**：命名规范、缩进、注释
3. **检查潜在 bug**：空指针、越界、类型错误、资源泄漏
4. **检查安全漏洞**：SQL 注入、路径穿越、XSS、硬编码密钥
5. **检查性能**：不必要的循环、重复计算、N+1 查询

## 输出格式

按严重程度分类输出：

- 🔴 **严重**：必须修复（bug、安全漏洞）
- 🟡 **建议**：应该改进（风格、性能）
- 🟢 **提示**：可以优化（可选改进）

每个问题给出：位置、问题描述、修复建议（附代码示例）。
